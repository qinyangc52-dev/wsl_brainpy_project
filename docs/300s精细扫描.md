# 300 秒精选参数扫描

## 实验设计

- `sigma`：`6.85`、`6.86`、`6.87`、`6.90`、`6.95`，共 5 个点。
- seed：`1256874` 到 `1256878`，每个 `sigma` 使用 5 个 seed。
- 总任务数：`5 × 5 = 25`。
- 每个任务：300 秒，原始模块放电率以 1 ms 分箱保存，即 1000 Hz。
- 固定参数：`delta=1.1`、`alpha=0.5`、`rho=1.0`、66 个脑区。
- 调度方式：单 GPU 串行运行，避免并发任务争抢显存。

扫描入口为 `scripts/run_fine_sigma_seed5_300s.py`。每个 seed 使用对应的正式网络 artifact：
`artifacts/full_seed_1256874` 至 `artifacts/full_seed_1256878`。

## 启动前检查

```bash
cd /root/rivermind-data/ecmm/wsl_brainpy_project
source /root/rivermind-data/ecmm/.venvs/ecmm-brainpy/bin/activate
export XLA_PYTHON_CLIENT_PREALLOCATE=false
python scripts/run_fine_sigma_seed5_300s.py --dry-run
```

`--dry-run` 只打印25条任务命令，不会启动仿真。

## 正式启动

```bash
cd /root/rivermind-data/ecmm/wsl_brainpy_project
source /root/rivermind-data/ecmm/.venvs/ecmm-brainpy/bin/activate
export XLA_PYTHON_CLIENT_PREALLOCATE=false
mkdir -p logs/fine_sigma_seed5_300s
tmux new -s ecmm300scan
python scripts/run_fine_sigma_seed5_300s.py --resume-incomplete \
  2>&1 | tee logs/fine_sigma_seed5_300s/master.log
```

按 `Ctrl+B` 后按 `D` 可退出 tmux 而不停止扫描。重新进入：

```bash
tmux attach -t ecmm300scan
```

查看总进度：

```bash
tail -f logs/fine_sigma_seed5_300s/master.log
```

结果写入 `runs/fine_sigma_seed5_300s/`。每个任务有独立的 `run.h5`、配置、manifest、
checkpoint 和 summary。扫描计划保存在 `runs/fine_sigma_seed5_300s/scan_plan.json`。

脚本会跳过已经完整完成的300秒任务。使用 `--resume-incomplete` 时，存在有效 checkpoint 的
未完成任务会断点续跑；无 checkpoint 的不完整目录不会被覆盖，脚本将停止并要求人工检查。
